# Changelog

## 0.1.1

- Add GitHub repository, homepage, and issue tracker links to the npm package metadata.
- Show email previews and link to documentation from the npm README.

## 0.1.0

- Generate responsive transactional email HTML and plain text from one input.
- Include branded headers, preheaders, action buttons, receipt tables, and footers.
- Ship default and dark palettes with custom theme overrides and English label fallback.
- Validate structured input, escape HTML by default, and reject unsafe link schemes.
- Include runnable examples, API and schema documentation, and HTML snapshot tests.
- Add password-reset, email-verification, and dashboard-welcome templates.
- Add six event templates with serif headlines, coordinated light and dark palettes, responsive details, and matching plain text.
- Make the default CommonJS export compatible with Mailgen's HTML and plain-text call pattern.
- Preserve the combined-output API under the named `PatraMail` export.
